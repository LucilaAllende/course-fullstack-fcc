## 📺 Taller Práctico: Incrustando Contenido con `<iframe>`

### 🎯 Objetivo del Taller
En este breve pero fundamental workshop, aprenderás a utilizar uno de los elementos más poderosos de HTML: el **`<iframe>` (Inline Frame)**. Este elemento es la herramienta clave para incrustar contenido de otra fuente (como videos de YouTube, mapas, o documentos externos) directamente en tu página web.

### 🛠️ Lo que Harás y Aprenderás

El código base HTML ha sido preparado para ti. Tu tarea principal será:

1.  **Integrar un Video:** Utilizarás el elemento `<iframe>` para **incrustar un video** de una plataforma externa (como YouTube o Vimeo) dentro de tu documento.
2.  **Manejo de Atributos:** Practicarás la configuración de atributos esenciales como:
    * **`src`:** Para definir la URL del contenido externo a incrustar.
    * **`width` y `height`:** Para controlar el tamaño visible del reproductor.
    * **Atributos de Seguridad:** Entenderás la importancia de atributos como `allowfullscreen` y las políticas de `sandbox` y `referrerpolicy` (aunque no sean el foco principal, son cruciales en el mundo real).
