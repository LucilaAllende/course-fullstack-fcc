## 📊 Taller de Datos: Reporte Académico de Alto Nivel

### 🎯 El Desafío
En este taller, transformarás datos académicos dispersos en una **matriz de información estructurada**. Tu misión es construir una tabla de calificaciones para un examen final de Cálculo, aplicando las mejores prácticas de arquitectura HTML para garantizar que los datos sean legibles, precisos y accesibles.

### 🛠️ ¿Qué vamos a lograr?

A través de este ejercicio, dominarás la anatomía completa de las **tablas profesionales en HTML5**, centrándote en:

1.  **Contextualización Semántica:**
    * Aprenderás a usar la etiqueta `<caption>` para darle una identidad propia a tu tabla, asegurando que el usuario sepa exactamente qué datos está consultando.

2.  **Arquitectura Modular:**
    * **`<thead>` (Cabecera):** Definición clara de las dimensiones de datos (Nombres, Apellidos y Calificaciones).
    * **`<tbody>` (Cuerpo):** Organización sistemática de la información individual de cada estudiante.
    * **`<tfoot>` (Resumen):** Creación de un espacio para el procesamiento de datos finales, como promedios generales.

3.  **Dominio del Layout de Celdas:**
    * Implementarás el uso de **`colspan`**, una técnica fundamental para fusionar columnas y crear reportes de resumen que mantengan la armonía visual de la tabla.

---

### 💡 ¿Por qué es importante?
En el mundo del desarrollo, presentar datos de forma desordenada es igual a no tener datos. Una tabla bien estructurada permite que los analistas, docentes y sistemas automáticos interpreten el rendimiento académico de manera inmediata y sin errores.
