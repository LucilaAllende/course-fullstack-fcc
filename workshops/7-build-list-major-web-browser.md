## 🌐 Taller Práctico: Creación de una Lista Maestra de Navegadores Web

### 🎯 Objetivo del Taller
Este workshop se enfoca en ir más allá de las listas básicas (`<ul>`, `<ol>`) para dominar la **estructura de definición (`<dl>`)**. Utilizaremos esta herramienta semántica para construir un **catálogo informativo y bien estructurado** de los navegadores web más importantes del mundo.

### 🛠️ Lo que Construirás y Aprenderás

Aunque el *boilerplate* inicial está listo, el valor de este taller reside en la correcta implementación de la **Lista de Definición**. Aprenderás a:

* **Estructura `<dl>`:** Establecer el contenedor semántico para la lista de términos y sus descripciones.
* **Términos de Definición (`<dt>`):** Designar correctamente el **nombre del navegador** (ej: Chrome, Firefox) como el término a definir.
* **Descripciones de Definición (`<dd>`):** Asociar información clave, características o el motor de renderizado de cada navegador al término correspondiente.

Al finalizar, no solo tendrás una lista, sino un **documento semántico** que relaciona términos con sus descripciones de manera formal, lo cual es esencial para accesibilidad y SEO.
