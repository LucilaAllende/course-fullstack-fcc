## 📅 Workshop: Arquitectura de Tablas Accesibles para Conferencias Tech

### 🎯 El Desafío
En este taller, construirás el horario oficial de una conferencia tecnológica. El reto no es solo alinear filas y columnas, sino aplicar estándares avanzados de **Accesibilidad Web (A11y)** para garantizar que cualquier asistente, independientemente de cómo navegue la web, pueda planificar su jornada sin barreras.

### 🛠️ ¿Qué vamos a construir y aprender?

Transformarás una simple lista de horarios en una herramienta de consulta profesional, dominando los siguientes pilares:

#### 1. Estructura Semántica Avanzada
* **Encabezados con Propósito:** Aprenderás a usar el atributo `scope` en las etiquetas `<th>` para definir claramente si un encabezado pertenece a una **fila** o a una **columna**.
* **Segmentación de Datos:** Organizaremos la información utilizando `<thead>`, `<tbody>` y `<tfoot>` para una lectura jerárquica impecable.

#### 2. Relaciones de Datos Complejas
* **Dominio de `rowspan`:** Aprenderás a fusionar celdas para representar eventos que duran varias horas o sesiones que ocupan múltiples tracks, manteniendo siempre la coherencia del árbol de accesibilidad.


#### 3. Contexto y Descripción
* **Uso de `<caption>`:** Implementarás títulos descriptivos que actúan como el "punto de entrada" para los lectores de pantalla, proporcionando contexto inmediato sobre el contenido de la tabla.


### 💡 ¿Por qué es fundamental este conocimiento?
Una tabla mal construida es un muro para un usuario de lector de pantalla. Al dominar las tablas accesibles, aseguras que la información crítica (como el horario de una charla magistral) sea **perceptible, operable y comprensible** para todos.
