## 🐾 Taller: Construyendo el Blog de Mr. Whiskers con Semántica Avanzada

### 🎯 Objetivo del Taller
En este workshop, desarrollarás un blog completo para el famoso gato **Mr. Whiskers**. El desafío no es solo mostrar información, sino utilizar el estándar de **HTML Semántico** para que los navegadores y lectores de pantalla entiendan perfectamente la jerarquía y el propósito de cada parte del sitio.

### 🛠️ Lo que Aprenderás y Aplicarás

A través de la construcción de este blog, dominarás el uso de etiquetas esenciales:

* **Encabezado Multimodal (`<header>`):** Aprenderás a agrupar el título principal con elementos visuales utilizando **`<figure>`** y **`<figcaption>`** para dar contexto a las imágenes.
* **Navegación Inteligente (`<nav>`):** Implementarás un menú de navegación con enlaces internos (anclas) para mejorar la experiencia de usuario dentro de la misma página.
* **Arquitectura de Contenido (`<main>`, `<section>`, `<article>`):**
    * Aprenderás a usar **`<main>`** para el contenido único.
    * Organizarás el sitio en **`<section>`** temáticas (About, Posts, Contact).
    * Utilizarás **`<article>`** para encapsular cada entrada del blog como una unidad de contenido independiente y reutilizable.
* **Información de Contacto Semántica:** Utilizarás la etiqueta **`<address>`** en el **`<footer>`**, la forma correcta y profesional de marcar datos de contacto en la web.
