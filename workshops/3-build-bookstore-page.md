## 📚 Taller: Construyendo una Página de Librería Digital

### 🎯 Objetivo del Taller
En este workshop práctico, nos sumergiremos en el desarrollo frontend creando una **Página de Librería** funcional e intuitiva. El objetivo principal es construir **tarjetas de libros (Book Cards)** que muestren de manera organizada la información clave de diversas obras.

### 🛠️ Lo que Aprenderás

Practicarás habilidades esenciales de estructuración HTML y organización de contenido:

* **Organización Avanzada con `<div>`:** Aprenderás a usar el elemento `div` para agrupar y segmentar bloques de contenido de manera lógica.
* **Gestión de Estilos con Clases:** Dominarás la aplicación estratégica de **clases** para aplicar estilos consistentes a múltiples elementos, como las tarjetas de libros.
* **Identificadores Únicos (IDs):** Utilizarás **IDs** para seleccionar y manipular elementos específicos dentro de tu página.
* **Creación de Componentes Reutilizables:** Diseñarás un *Book Card* que servirá como plantilla para presentar cualquier libro de la librería.
