## 🏨 Taller de Desarrollo: Sistema de Feedback Hotelero

### 🎯 El Desafío
En este taller, pasarás de crear sitios informativos a construir **herramientas de interacción real**. Tu misión es desarrollar un formulario de retroalimentación para un hotel, diseñado para capturar la experiencia del huésped de manera precisa y profesional.

### 🛠️ ¿Qué vamos a lograr?

A través de este ejercicio, dominarás la arquitectura de los **formularios en HTML5**, enfocándote en tres pilares fundamentales:

1.  **Estructura y Organización:**
    * Aprenderás a usar `<fieldset>` y `<legend>` para agrupar la información (Datos personales, Calificaciones, Opiniones), facilitando la lectura tanto para usuarios como para lectores de pantalla.
    
2.  **Captura de Datos Multimodal:**
    * **Selección Única:** Uso de `radio buttons` para decisiones binarias.
    * **Selección Múltiple:** Implementación de `checkboxes` para identificar múltiples preferencias.
    * **Listas Dinámicas:** Uso de menús desplegables (`select`) para estandarizar las calificaciones.

3.  **Validación y Experiencia de Usuario:**
    * Implementarás validaciones nativas (`required`, `min`, `max`) para asegurar que los datos recibidos sean útiles.
    * Optimizarás la accesibilidad vinculando correctamente etiquetas (`label`) con sus respectivos campos de entrada.

---

### 💡 ¿Por qué es importante?
Los formularios son el puente entre el usuario y el servidor. Un formulario bien estructurado no solo mejora la **tasa de conversión**, sino que garantiza que la información llegue limpia y lista para ser procesada.
