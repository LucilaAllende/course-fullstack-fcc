## 📝 Laboratorio: Creación de un Formulario de Encuesta Profesional

### 🎯 El Desafío
En este laboratorio, tu misión es diseñar y construir una aplicación de **Formulario de Encuesta** completamente funcional y semántica. El objetivo es crear una interfaz que no solo recolecte datos, sino que guíe al usuario a través de una experiencia de llenado clara, validada y con tu propio estilo personal.

### 🛠️ ¿Qué vamos a construir y aprender?

Dominarás la captura de datos en la web cumpliendo con las siguientes metas técnicas:

#### 1. Estructura y Jerarquía Semántica
* Configurarás un encabezado impactante con un `<h1>` para el título y un `<p>` descriptivo, ambos debidamente identificados para cumplir con los estándares de accesibilidad.

#### 2. Validación Nativa de HTML5
Implementarás un sistema de seguridad de datos sin necesidad de JavaScript:
* **Campos Obligatorios:** Uso del atributo `required` en nombres y correos.
* **Formatos Específicos:** Validación automática de correos electrónicos y campos numéricos con límites definidos mediante `min` y `max`.
* **Placeholders Inteligentes:** Guía visual dentro de los campos para mejorar la tasa de completado.

#### 3. Variedad de Controles de Usuario
Aprenderás a elegir el componente adecuado para cada tipo de pregunta:
* **Dropdowns (`<select>`):** Para selecciones múltiples estandarizadas.
* **Radio Buttons:** Para decisiones únicas donde las opciones son mutuamente excluyentes.
* **Checkboxes:** Para permitir al usuario elegir múltiples intereses o características.
* **Áreas de Texto:** Para capturar opiniones libres y detalladas.

#### 4. Accesibilidad Profesional
* Vincularás cada campo con su respectivo `<label>`, asegurando que el formulario sea navegable mediante teclados y lectores de pantalla.

### 💡 Puntos Clave para el Éxito
El reto no es solo que el formulario "funcione", sino que sea **robusto**. Aprenderás a usar atributos como `id`, `name` y `value` para que, al presionar el botón de **Submit**, la información esté perfectamente organizada para el servidor.
